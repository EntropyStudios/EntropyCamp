# 运控任务浏览

主页的“运控任务”进入 `performance.html`。默认 API 地址为 `http://192.168.100.247:8765`，可在“连接设置”修改。

本版本为只读浏览：部门、状态、人员 ID、姓名片段、关键词、截止日期范围、归档范围和排序均透传树莓派 API。默认部门为实际字段值“运控”、不含归档。后端按每批 200 条读取并合并去重，所有符合条件的任务放在同一页面连续向下浏览，没有翻页按钮。日期边界含当天，以北京时间解释；“今天起”可直接查看今天及之后截止的任务。所有已应用的筛选组合保存在浏览器，刷新或重新进入页面自动恢复；密钥不在浏览器持久化。

状态选项、人员和详情字段从 `/v1/meta`、`/v1/people` 动态加载。点击任务读取实时详情，数字空值不会显示为 0。附件展示文件名；不提供下载代理。分页总数来自后端完整筛选结果。前台每 30 秒查询，重新进入标签页立即刷新；服务返回 stale 时标记“数据暂未更新”。详情窗口不会被列表轮询覆盖。

列表按 record_id 复用卡片 DOM，刷新时仅修改内容有变化的卡片，顺序未变时不移动节点。新增卡片播放入场动画，已有卡片不会在每次轮询时重新淡入，避免周期性闪烁并保留焦点与悬停状态。`test_performance_render.py` 验证无变化刷新、局部更新、排序和移除。

浏览器只访问本地 `/api/performance/*`，本机后端附加 Bearer 认证请求树莓派。配置存于 EntropyCamp 数据目录的 `performance-api.json`，以原子替换写入、权限 0600，不在静态 HTTP 根目录或 Git 中。设置接口只返回地址和是否配置，不回传密钥。换地址且未填新密钥会清除旧密钥，禁止 HTTP 重定向以避免向其他地址泄漏认证。只开放读取接口，没有新增、编辑、归档、恢复或永久删除入口。

用户已明确授权将客户端只读和读写凭据保存到本机私有配置。当前只读凭据用于请求，读写凭据仅预留（writeToken），没有写入接口；管理员凭据未复制。换地址或清除密钥同时移除预留读写凭据。验证真实业务数据时只读；模拟分页、详情验收使用独立临时服务和虚构记录。

测试：`python3 -m unittest test_performance_client -v`。覆盖凭据隐私/权限、换地址清理、过滤参数白名单、只读路由、权限错误和异常 URL。
