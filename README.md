# 提醒卡片

一个无需构建、无需安装依赖的本地提醒卡片应用，可选关联本机 Codex 对话。

## 启动

双击 `启动提醒卡片.sh`，或运行：

```bash
python3 run.py
```

普通计时卡也可以直接用浏览器打开 `index.html`；Codex 对话关联需要通过 `run.py` 启动。

## 功能

- 新建提醒卡片
- 设置卡片标签
- 设置提醒间隔
- 卡片创建后点击整张卡片，从点击时刻开始倒计时
- 时间到后卡片亮起
- 左上角“每日名钟”会按北京时间日期稳定轮换，也可点击右上角按钮当天手动切换
- Corpus Clock：60 齿逃逸轮每秒顺时针前进一齿，两只擒纵足交替锁止；钟面包含 60 秒槽、60 分槽、48 个小时/刻钟槽，并模拟 Chronophage 的摆动、眨眼、整分咬合与五分钟归准
- Big Ben / 伊丽莎白塔：采用修复后的普鲁士蓝、金色与乳白玻璃方案；时分针按真实重力擒纵每 2 秒跳进，不添加秒针；每刻钟用无声金色光波模拟 Westminster Quarters，并借用“天黑后议会开会时亮起”的 Ayrton Light 表示上班中
- 所有可读钟面统一显示北京时间（`Asia/Shanghai`），不依赖浏览器或系统时区；Corpus Clock 保留吞时误差，Big Ben 的两秒跳针与报刻也按北京时间运行
- Prague Orloj / 布拉格天文钟：以两扇哥特使徒窗、四个上盘活动人偶、偏心黄道天文盘、Mánes 式历盘和四尊下盘静态木雕重建现存真钟；金手、太阳标记、历盘日界和整点机关映射北京时间，月相、恒星时、巴比伦不等时与日落起算的旧捷克时仍保留布拉格天文结构
- Bern Zytglogge / 伯尔尼时钟塔：按完整东立面校正为较大的黑金双头指针主盘、较小的红蓝天文盘，以及只伴随下盘的右侧人物阁；读时、日期、报刻与人物秀按北京时间运行，黄道恒星日、月针和月相保留历史机械节奏；整点前依次模拟三次雄鸡、七熊队、小丑、Chronos、金狮和塔内击钟状态
- 有到期提醒时自动聚焦主卡，并把提醒区控制在一屏内；其他卡片收纳到侧边或底部
- 卡片进入聚焦区、回到普通区或标记已读时使用平滑布局动画
- 点击亮起的卡片后熄灭并重新计时
- 编辑和删除卡片
- 已有或新建卡片可选关联 Codex 对话
- Codex 关联列表同时支持本机与已配置的 SSH 主机；远程卡片会显示来源标签，SSH 断线时本机卡片不受影响
- 关联后增量监听 Codex 对话，新回复完成后实时亮起
- 点击上班后清零本班计数，从 `00:00:00` 记录本班工作时长，并统计所有已关联 Codex 对话的完成次数
- 点击下班后冻结本班计数与工作时长，并暂停提醒与 Codex 完成监听；刷新页面仍会保留当前班次状态
- 日报记录页可选择本班关联过的 Codex 对话，并导出 Markdown 或 JSON
- 程序通过追加式 rollout 文件的尾部窗口读取 `/api/codex/work-log`，只解析上班时间后的对话内容，并缓存未变化的结果
- 多剪贴板页可保存多条 TXT 原文或 Markdown，支持阅读/源码双模式、搜索、格式筛选、复制、编辑、置顶和删除
- 剪贴卡片按内容自动排版，并在新增、筛选、置顶、展开和删除时平滑重排；数据只保存在浏览器本地
- 页面使用实时事件连接，并在重新聚焦时补查；60 秒低频同步用于防止休眠漏报
- 点击整张亮起的卡片标记已读，打开 Codex 对话不会自动熄灭
- 浏览器本地保存
- iPhone Scriptable 小组件通过独立的 `127.0.0.1:8003` 只读摘要端口显示上班状态、工作时长、完成次数和前四项提醒；完整主页与后台接口不会暴露，配置见 `docs/IPHONE_WIDGET.md`

界面采用极简黑白圆角与轻量液态玻璃风格，只保留提醒所需功能。
